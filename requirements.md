# 📋 System Requirements & Dependencies

`yt-dlp-pro` is a lightweight, modular YouTube downloading suite designed for Linux environments. It relies on standard Unix utilities and modern media tools.

## 🛠 Required Tools
- **Bash** (v4.0+) — For orchestrating the modular shell scripts.
- **Python** (v3.8+) — For running the metadata/chapter embedding helper script.
- **yt-dlp** — The core engine for fetching video data, playlists, and formats.
- **FFmpeg** — Required for merging video/audio streams and embedding chapters/metadata.
- **mpv** (Optional) — Required if you want to preview search results directly in your terminal/GUI.
